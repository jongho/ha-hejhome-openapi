# Hejhome Open API for Home Assistant

[![HACS Default](https://img.shields.io/badge/HACS-Default-41BDF5.svg)](https://hacs.xyz)

> **비공식 HA 통합입니다.** 헤이홈(Hejhome) 및 고퀄(GOQUAL)과 관계가 없으며, 공식 지원을 받지 않습니다.
> Unofficial — not affiliated with or endorsed by Hejhome / GOQUAL.

헤이홈 기기를 Home Assistant에 연결하는 커스텀 통합입니다. 고퀄(GOQUAL)이 공개한 **Open API v3**를 씁니다. API는 공식이지만 통합은 개인이 만들었으므로, 문제가 생기면 헤이홈 고객센터가 아니라 이 저장소 이슈로 알려 주세요.

헤이홈 for Web(square.hej.so)의 비공식 API로 만든 [ha-hejhome](https://github.com/jongho/ha-hejhome)를 대신합니다. 헤이홈 for Web은 2026년 12월 22일에 서비스를 끝냅니다([공지](https://m.hej.life/board/free/read.html?no=131487&board_no=1)).

> 실제로 시험해 본 기기는 모션 센서(GKZ-MO021), 온습도계(GKZ-TH141), 스마트 컬러 전구 Z26 세 가지입니다. 나머지 기기는 API 문서만 보고 만들었으니, 잘 안 되면 이슈로 알려 주세요.

## 필요한 것

- Home Assistant 2025.12 이상
- 헤이홈 파트너스 포털에서 발급한 API 키 (아래 [API 키 발급](#api-키-발급) 참고)
- 그 API 키에 연결한 헤이홈 계정

## API 키 발급

API 키는 헤이홈 파트너스 포털에서 무료로 받습니다. 한 사람이 한 번만 하면 됩니다.

1. **회원 가입:** [partners.goqual.com](https://partners.goqual.com)에 들어가 이메일 인증을 하고, 「파트너스 포털 이용약관」과 「Open API 이용약관」에 동의합니다.
2. **조직 만들기:** 애플리케이션과 API 키는 조직 안에 만듭니다. 조직을 신청하면 고퀄이 승인한 뒤 만들어집니다.
3. **애플리케이션 만들기:** 조직 안에 애플리케이션을 하나 만듭니다. 이름은 "Home Assistant"처럼 알아보기 쉽게 정하면 됩니다.
4. **API 키 발급:** 애플리케이션에서 API 키를 발급합니다. **키는 발급할 때 한 번만 보이므로** 바로 안전한 곳에 적어 둡니다.
5. **헤이홈 계정 연결:** 포털에서 헤이홈 앱 계정의 아이디와 비밀번호를 넣고, 휴대폰이나 이메일로 온 인증번호를 넣어 계정을 연결합니다.
6. **허용 IP 등록(권장):** 애플리케이션에 집의 공인 IP를 등록하면, 키가 새어 나가도 다른 곳에서는 쓸 수 없습니다.

알아 둘 점:

- 헤이홈 앱에서 **장소 소유자**인 계정을 연결해야 그 장소의 기기가 보입니다. 관리자나 구성원으로 들어가 있는 장소의 기기는 보이지 않습니다.
- 헤이홈 계정 하나는 애플리케이션 하나에만 연결할 수 있습니다.
- 집 공인 IP가 바뀌면 허용 IP에 없는 곳에서 호출하는 것이 되어 통합이 멈춥니다. 이때 HA에 수리 알림이 뜨면 포털에서 IP를 고쳐 주세요.
- API 키는 다른 사람에게 주거나 GitHub 같은 공개된 곳에 올리면 안 됩니다. 새어 나갔다면 포털에서 바로 폐기하고 새로 발급합니다.
- 키를 바꿀 때는 새 키를 발급하고, HA에서 통합의 **재설정**으로 새 키를 넣은 뒤, 이전 키를 폐기합니다.

## 설치 (HACS)

1. HACS에서 "Hejhome Open API (Unofficial)"를 검색해 내려받고 Home Assistant를 재시작합니다.
2. **설정 → 기기 및 서비스 → 통합 추가**에서 "Hejhome Open API (Unofficial)"를 고르고 API 키를 넣습니다. 집이 여러 곳이면 연결할 집을 고릅니다.

검색해도 나오지 않으면 HACS → 오른쪽 위 메뉴 → **사용자 지정 저장소**에 이 저장소 주소를 넣고, 유형을 **통합**으로 골라 추가한 뒤 1단계부터 하면 됩니다.

HACS 없이 설치하려면 `custom_components/hejhome_openapi/` 폴더를 HA의 `/config/custom_components/`에 복사하고 재시작합니다.

## 지원 범위

| 엔티티 종류 | 다루는 값 |
|---|---|
| 센서 | 온도, 습도, 배터리, 조도, 전력·전류·전압, 일산화탄소 농도, 필터 수명 등 |
| 이진 센서 | 문 열림, 움직임, 재실, 누수, 연기, 일산화탄소, 잠금, 연결 상태 |
| 스위치 | 플러그, 벽 스위치(여러 구 포함) |
| 조명 | 켜기/끄기, 밝기, 색온도, 색상 |

- 헤이홈 API는 상태가 바뀌어도 먼저 알려 주지 않습니다. 그래서 30초마다 상태를 가져옵니다. 간격은 옵션에서 30~300초로 바꿀 수 있습니다.
- 호출 한도(429)에 걸리면 가져오는 간격을 잠시 늘립니다.
- 잠깐 연결이 끊기면 세 번까지는 마지막 값을 그대로 보여 줍니다.
- API 키가 막히거나 바뀌면 다시 넣는 화면이 나옵니다.
- 진단 파일에서는 API 키와 계정 정보를 가립니다.

## 개발

```bash
python3 -I -B tests/test_api.py     # api/ 단위 테스트 (표준 라이브러리만, HA 불필요)
python3 -I -B tests/live_check.py   # 실제 API 조회만 (제어 없음)
```

`live_check.py`는 저장소 최상위의 `api-key.env`(`HEJHOME_API_KEY=...`)에서 키를 읽습니다. 이 파일은 `.gitignore`에 있어 커밋되지 않습니다. `docs/samples/`는 실제 응답에서 id와 이름을 가린 것입니다.
